# Smart Keychain App

Smart Keychain App — offline-first мобильное Flutter-приложение для управления брелоком или игрушкой с круглым цветным экраном. На экране предполагается показывать процедурно анимированные глаза, эмоции, мордочки животных и изображения пользователя.

Телефон отвечает за подключение и настройку устройства, выбор контента, предпросмотр, импорт и обрезку изображений, а в следующих версиях — за автоматизации. Связь с реальным устройством будет работать через Bluetooth Low Energy (BLE).

Физического прототипа и утверждённого BLE-протокола пока нет. Поэтому первый MVP строится вокруг полноценного Virtual Device Simulator: с ним можно разрабатывать и проверять основной пользовательский сценарий без hardware. Когда устройство появится, `VirtualDeviceRepository` будет дополнен `BleDeviceRepository`, а UI и бизнес-логика останутся прежними.

Главный архитектурный принцип:

```text
UI / Application Logic
          │
          ▼
  DeviceRepository
      ┌───┴───┐
      ▼       ▼
 Simulator   BLE device
```

## Текущее состояние

Реализован первый рабочий вертикальный срез software MVP:

- поиск и подключение виртуального брелока;
- экран устройства с круглым preview;
- библиотека встроенных сцен;
- общий гардероб встроенных и пользовательских образов;
- импорт, crop, редактирование и удаление пользовательских изображений;
- подтверждаемый устройством цикл применения образа с retry при ошибке;
- production Settings с выбором Obsidian, Pearl или System, информацией об
  устройстве, регулировкой яркости и подтверждаемым отключением;
- настройка latency симулятора в debug-режиме;
- отключение и возврат к поиску устройства;
- русская локализация, unit-, widget- и golden-тесты.

BLE, кодирование изображений для физического дисплея и автоматизации остаются
следующими этапами roadmap.

## Быстрый старт

Проект использует Flutter `3.47.1`; версия зафиксирована в `.fvmrc`.

```bash
flutter pub get
flutter test
flutter run
```

При использовании FVM добавьте `fvm` перед каждой командой Flutter, например:

```bash
fvm flutter test
```

Backend и физическое BLE-устройство для запуска текущего MVP не требуются.

## Проверка основного сценария

1. Запустите приложение и нажмите «Подключить» у Demo Keychain.
2. Откройте «Гардероб», выберите образ и дождитесь подтверждения применения от
   виртуального брелока.
3. Импортируйте фотографию, настройте crop, затем проверьте редактирование и
   удаление созданного образа.
4. Из Home откройте Settings, смените appearance и яркость, затем вернитесь
   назад без повторного подключения устройства.
5. В debug-сборке отдельно откройте настройки симулятора и измените задержку.
6. В информации об устройстве подтвердите отключение и убедитесь, что приложение
   вернулось к экрану поиска.

Начать знакомство: [индекс документации](docs/README.md).
