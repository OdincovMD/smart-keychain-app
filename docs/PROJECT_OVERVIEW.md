# Smart Keychain App — обзор проекта

> Назначение продукта, стратегия разработки и текущее состояние.

> Источник: исходная спецификация версии 0.1 (Draft / Initial Architecture).

## Project Overview

Проект представляет собой мобильное приложение для управления физическим брелоком/игрушкой с круглым цветным экраном.

На экране устройства могут отображаться:

- живые анимированные глаза;
- эмоциональные состояния;
- анимированные мордочки животных;
- статические изображения пользователя;
- в перспективе — пользовательские и загружаемые анимации.

Физический экран может быть встроен в корпус/игрушку.

Мобильное приложение является основным интерфейсом настройки устройства.

Связь телефона с физическим устройством предполагается через **Bluetooth Low Energy (BLE)**.

---

## Current Development Strategy

Так как физического устройства пока нет, разработка начинается с **Virtual Device Simulator**.

На первом этапе приложение должно позволять полностью пройти пользовательский сценарий:

```text
Application
    ↓
Virtual Keychain
    ↓
Select Scene
    ↓
Animated Eyes
    ↓
Import Photo
    ↓
Crop
    ↓
Preview
    ↓
Set as active
```

После появления физического устройства необходимо будет добавить:

```text
BleDeviceRepository
```

без существенного изменения:

- UI;
- бизнес-логики;
- библиотеки контента;
- редактора изображений;
- автоматизаций;
- виртуального экрана;
- моделей данных.
